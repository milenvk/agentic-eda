== The Three Mapping Types

Each chapter maps to the application in one of three ways:

* **Workflow chapter** — introduces or extends a business workflow; new components arrive only
  because that workflow slice needs them.
* **Component chapter** — a new agent/service/store is the star; workflows advance as a side
  effect.
* **Layer chapter** — a cross-cutting concern (testing, security, observability, cloud) applied
  across the existing system; it owns no new business workflow but touches many.

Every chapter still ends with the working system one increment richer — the type only says what
carries the narrative.
